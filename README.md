### 🚀 Live Products & Platforms

#### 🛡️ [AuxAI](https://auxai.pages.dev/)
* **Independent Trust Layer for AI:** A lightweight monitor that watches any autonomous or AI-driven system inference-by-inference.
* **Key Features:** Catches silent failures independent of confidence scores, performs multi-signal edge validation, and executes safe in-process rollbacks/healing without needing access to model weights.
* **Primary Domains:** Autonomous robotics, defense/ISR, industrial automation, and edge deployments.

#### 🏭 [SILDA](https://sildai.pages.dev/)
* **OT/IT Break-and-Inspect Mediation Authority:** A Level 3.5 industrial cybersecurity platform that enforces security inline.
* **Key Features:** Per-asset AI behavior scoring, cryptographic forensic audit trails (SHA-256 + Ed25519), financial ROI per blocked threat, and privacy-preserving federated learning across plants without cloud dependency.
* **Compliance Alignment:** NIST 800-82 R3, IEC 62443 SL-2, and MITRE ATT&CK ICS v14.

#### 📱 [HeliTrust](https://healthi.pages.dev/)
* **Privacy-First AI Safety Monitoring:** Turns standard edge hardware (phones) into a 24/7 safety and fall-detection monitor.
* **Key Features:** Uses **Unifying Contextual Weights** to process motion telemetry entirely on-device, ensuring absolute GDPR compliance where raw sensor data never touches a cloud server.
* **Primary Domains:** Eldercare facilities, lone-worker safety, and remote physiological baseline tracking.
